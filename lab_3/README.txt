# CS302JSC — JavaScript Practical Lab Session 3

## How to run
1. Keep `index.html` and `script.js` in the same folder.
2. Open `index.html` in a browser.
3. Press F12 (or Ctrl+Shift+I).
4. Open the **Console** tab.
5. All Part 0–6 outputs will appear there.

The code follows the worksheet requirement to use the HTML + script.js method and avoids loops.
